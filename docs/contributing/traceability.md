# Traceability

This page maps every requirement (R1 to R16), every acceptance scenario (S1 to S15) and every binding constraint to the design elements that meet it and the tests that prove it. Design elements link to sections of [Architecture](architecture.md) and records in [Decisions](decisions.md). Each scenario's full CI and evidence paths are in `feature_list.json` at the repo root. A test listed here and not yet written is planned; its path is where it will live.
