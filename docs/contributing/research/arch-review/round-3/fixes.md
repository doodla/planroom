# Architecture review round 3: fixes

One section per fix cluster: one line per finding, saying what changed and where, or "known gap" or "accepted risk".

## Writes, kernel and packs

- correctness-1 (F1): a person's field wins over any automatic write. An auto-enabled effect, a prefill or an `infer` output never sets a field whose current value comes from a person's edit, whatever its base; the decision is `Superseded`, listed in Diffs, with no card, and the runner skips such subjects. Changed in architecture.md (Main flows 5, The write path diagram, Layers paragraph, Conflicts, The decision loop diagram and bullets, A decision kind, Cache and records, M2 decision-runner slice), contracts.md (`Outcome::Superseded`, `DecisionKind.effect`), new DR-73, DR-5 and DR-50 amended, feature_list.json C12, traceability R6 and R9.
- correctness-2 (F2): a `route_call` whose method or path is a parameter of its enclosing function is bound at each in-container call site with literal or template arguments, one route call per call site with both lines as evidence; interpolated segments normalize to `{}`; a non-literal base takes its host from a same-file `env_read` that compose sets. Changed in architecture.md (Hints and linkers table and a new bullet, R-3, M1 linkers slice), DR-12 amended, feature_list.json S4 tests, traceability R2 and S4.
- correctness-3 (F3): a pending canvas edit keeps its minting tab's client ID and any flushing tab sends it; the request hash covers command, arguments, base, actor and client, never transport fields. Changed in architecture.md (The canvas Writes, Idempotency and retries, M1 fold slice), contracts.md (`WriteCommon.client`), DR-73, DR-5 and DR-8 amended, feature_list.json S8 tests, traceability R10 and S8.

Changed in architecture.md (Store schema backup paragraph and restore bullet, Store integrity row, M1 backup slice), contracts.md (Store schema and migrations, `Scan.snapshot`, `Status`), DR-73, DR-53 amended, feature_list.json C14, traceability R10.
